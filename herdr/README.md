# Herdr config snapshot

Copiado de uma máquina Ryoku/Omarchy em **2026-10-31**, a pedido do dono do
repositório, junto com o projeto:

| Arquivo | Origem |
|---|---|
| `config.toml` | `~/.config/herdr/config.toml` |
| `keys.json` | `~/.config/herdr-app/keys.json` |
| `settings.json` | `~/.config/herdr-app/settings.json` |

O `config.toml` espelha o `tmux.conf` do Omarchy (prefixo `Ctrl+Space`, panes,
tabs e workspaces). O `keys.json` é o keymap do app Herdr usado como referência
do que já é atalho global lá dentro.

Nada aqui é lido pelo `import-omarchy-key-bindings`; é um backup de referência.
Nenhum segredo, token ou caminho privado foi encontrado nos arquivos.
